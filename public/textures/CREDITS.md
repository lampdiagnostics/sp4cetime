# Image credits

- `earth.jpg` — NASA Visible Earth, Blue Marble (public domain), via the three-globe package's example image, reduced to 2048 × 1024.
- `moon.jpg` — Solar System Scope (https://www.solarsystemscope.com/textures/), based on NASA imagery, CC BY 4.0. Via github.com/homer-jay/solar-system-textures.
- `../sky/milkyway.jpg` — Solar System Scope Milky Way, CC BY 4.0 (same source), point stars removed, brightness stretched, blended with the d3-celestial Milky Way outline (BSD-3-Clause), in galactic coordinates.

- `earth-coast.bin`, `earth-borders.bin` — Natural Earth (public domain, https://www.naturalearthdata.com): 1:50m coastline, 1:110m lakes and land borders, via github.com/nvkelso/natural-earth-vector, simplified to about 3 km. Built by `scripts/build_earth_lines.py`.

The photographic maps are built by `scripts/build_textures.py`.

- `../places.json` — Natural Earth 1:10m populated places (public domain): 7,342 towns with their centres, regions, countries and time zones (towns missing a zone take the nearest town's in the same country). Built by `scripts/build_places.py`.
